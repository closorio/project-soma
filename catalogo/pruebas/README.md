# .litematic de prueba

Archivos reales para `bot/probar_estructuras_seco.js`, no forman parte del catálogo. Vienen de las pruebas de
[schematic4j](https://github.com/SandroHc/schematic4j) (`src/test/resources/schematics/litematica/v5/`), con licencia MIT
(`LICENSE-schematic4j`).

- `simple.litematic`: 5×5×5, Size con y y z negativas, una puerta y un cofre doble.
- `mansion.litematic`: 39×41×40, Size con z negativa, MC 1.16 (trae `grass`, hoy `short_grass`), trampillas y faroles colgantes.
